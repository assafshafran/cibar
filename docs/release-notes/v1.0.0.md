The first release of CIBar: your builds in the Mac menu bar.

- **Azure Pipelines:** builds in a project, for all pipelines or the ones you choose.
- **GitHub Actions:** workflow runs for a repository, or for one workflow file.
- **Vercel, Netlify and others:** deploys that report back to GitHub as commit statuses.
- **Menu bar icon:** a three-stage pipeline that pulses while a build runs, and turns green, red or orange when it finishes until you look.
- **Menu:** every source's latest runs fit without scrolling, running builds are always shown, and *Show more* reveals the history.
- **Notifications:** when a build finishes, opening the run when clicked.
- **Update check:** CIBar asks GitHub once a day whether a newer version is out, and tells you in the menu and with a notification. Turn it off, or check by hand, in Settings → Updates.
- **Read-only tokens:** stored on your Mac only. No account and no analytics.

Requires macOS 15 or later. Open the disk image, drag CIBar to Applications, open it, and click the icon in the menu bar to add your first pipeline.
