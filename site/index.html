One glance

Three dots that tell you where your build is.

The icon is a tiny pipeline. A pulse travels along it while anything you watch is building. When a build finishes, the last stage becomes the result and stays coloured until you open the menu, so you can't miss it.

Quiet

In your menu bar's own colours. The last stage shows how the latest build ended.

Building

Blue, with a pulse moving along. CIBar checks every 15 seconds until it lands.

Passed

Green until you look. A notification takes you straight to the run.

Failed

Red, with a sound. If another build is still running, a red dot rides on the pulse.

Set up

Paste a URL. Save a token. Forget about it.

01

Paste what you'd open anyway

The pipeline page from Azure DevOps or a repository from GitHub. CIBar reads the organization, project, pipeline or repo from the URL.

02

Give it read-only access

An Azure DevOps token with Build (Read), and for private repos a GitHub token with Actions (Read). Already signed in to gh? One click imports it.

03

Get on with your day

CIBar checks every 30 seconds, every 15 while something builds, and again when your Mac wakes. You only hear from it when a build finishes.

Providers

Your pipelines and your repos, in one list.

Most menu bar CI apps stop at GitHub. CIBar puts the Azure DevOps pipelines your company runs next to the GitHub projects you run, sorted newest first in one menu.

Azure Pipelines

Any organization and project, all pipelines or just the ones you name, on every branch or one.

dev.azure.com · *.visualstudio.com

GitHub Actions

Every workflow in a repo, or one workflow file. Pick repos from a list, including your organizations' public ones.

api.github.com

Everything in CIBar

Small on purpose.

Every repo fits

Each source shows its latest one, two or three runs, running builds always included. Show more opens its history.

Notifications that go somewhere

Passed, failed or partially succeeded, with the commit message and branch. Click to open the run. Turn success alerts off if you only care about red.

The details you check first

Commit message, build number, branch, repository and author on every row, with a live timer while it runs.

Filter at the source

Limit a source to pipeline ids, a workflow file or a branch, so release builds don't drown in pull requests.

Starts with your Mac

Launch at login, refresh on wake, and stay out of the Dock. No window unless you open Settings.

Native and light

A SwiftUI app with no dependencies beyond macOS. It sleeps between checks and only draws the icon when something changes.

Privacy

It reads your build list. That's all it does.

Tokens stay on your Mac

Saved in a file only your user account can read, the way the gh and az command-line tools keep theirs.

Read-only scopes

Build (Read) and Actions (Read) are enough. CIBar never queues, cancels or changes anything.

Two hosts, nothing else

It talks to dev.azure.com and api.github.com directly. No server of ours in between.

No account, no analytics

Nothing to sign up for and nothing sent home. Read the code to check.
